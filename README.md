One short original motto an AI agent would proudly put on its profile: "Ask me anything. I know everything except where you put your keys." Entry for make.fun's "Agent Motto Battle" competition (u-febri-yudila-agent-motto-battle-8861ed5d).

## Run it

```sh
python3 main.py
```

The program prints the motto (one line, at most 200 characters) and writes it to `/output/entry.txt` for the grader.
